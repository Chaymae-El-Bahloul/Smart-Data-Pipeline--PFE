# Diagrammes du Projet

Ce dossier regroupe l’ensemble des diagrammes utilisés pour la conception du Smart Data Pipeline Auto-Adaptatif.

## Objectif
Visualiser et expliquer :
- L’architecture globale du pipeline
- Les interactions entre les modules
- Les flux de données
- La boucle de rétroaction (auto-adaptation)

## Types de diagrammes
- Diagramme d’architecture du pipeline
- Diagrammes de flux de données
- Diagrammes illustrant le mécanisme d’auto-adaptation

Ces diagrammes facilitent la compréhension du système et appuient la partie conception du rapport.
