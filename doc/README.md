# Documentation du Projet

Ce dossier contient l’ensemble des documents académiques liés au Projet de Fin d’Études.

## Contenu
- **research/** : Partie recherche (état de l’art, concepts, méthodologie)
- **report/** : Rapport académique du PFE
- **presentation/** : Supports de présentation (réunions, soutenance)
- **diagrams/** : Diagrammes d’architecture et de flux
- **algorithm/** : Algorithmes et pseudo-codes du pipeline

Chaque sous-dossier possède son propre README pour expliquer son contenu et son rôle dans le projet.
